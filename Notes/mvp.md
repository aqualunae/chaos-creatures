# Minimum Viable Playable

Thinking about it, I've been focusing on the idea of an inventory system, but it might not be part of the March deadline MVP. Randomizing the creatures might seem like a stretch goal, but I already have some of that work done, so I'd like to include it as soon as I'm able to. At least the appearances, if not the skills.

Looking at the goals on the Agreement, it feels like I should have at least one goal that isn't just "develop a system that works". Since I've been a solo dev for the last year, I'd like my third goal to be good documentation and clear communication.

## The Real Minimum

- title screen
- new game
- select starter creature
- overworld
- player movement
- talk to npc (explains encounters)
- creature encounter
- combat (turn based, select skill)
- victory or defeat
- save game
- load game

## Slightly More

- creatures randomized
- use item to befriend creature
- menu to select which creature in your party is sent into combat
- experience and leveling (increase stats, new skills available)
- items can be found and picked up in overworld
- healing items

## Endgame

- npc will challenge you to combat once you reach a certain level
- defeating them is the win condition
